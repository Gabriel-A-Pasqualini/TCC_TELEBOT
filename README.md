# Telegram AI Bot (Python) - TCC 2022

🎓 **Project:** TCC 2022 – Approved  
This Telegram bot is a Python AI chatbot built using **ChatterBot** and **PyTelegramBotApi**, developed as a college final project.

## Overview

- AI-powered conversational bot using **ChatterBot**
- Telegram integration using **PyTelegramBotApi**
- Persistent storage with **PostgreSQL** (via Docker)
- Fully containerized for easy deployment

## Features

- Intelligent AI chat responses
- Stores conversation history in PostgreSQL
- Works directly within Telegram
- Easy deployment using Docker

## Tech Stack

- Python 3.10+
- [ChatterBot](https://pypi.org/project/ChatterBot/)
- [PyTelegramBotApi](https://pypi.org/project/pyTelegramBotAPI/)
- PostgreSQL 14 (via Docker)
- Docker Compose for containerization
